# ExamForge 性能测试记录

以下数据来自项目本地测试环境，硬件、Docker 资源限制、数据量和运行时间都会影响结果，不应直接视为生产环境容量承诺。原始 JTL / HTML 报告未提交仓库。

## 1000 虚拟用户稳态测试

- 虚拟用户：1000
- 稳态持续时间：600 秒
- HTTP 请求数：90,168
- HTTP 错误率：0%
- 观测吞吐量：约 150.28 req/s
- 平均响应时间：15.28 ms
- P95：20 ms
- P99：53 ms

该计划主要覆盖登录和持续查询考试列表，不创建考试记录。

## 1000 虚拟用户完整考试流程

- HTTP 请求数：15,000
- HTTP 错误率：0%
- 开考：1000 次
- 答案保存：10,000 次
- 主动交卷：1000 次
- GRADE Outbox 发送：1000 条
- 观测吞吐量：约 157.47 req/s
- 平均响应时间：25.42 ms
- P95：60 ms
- P99：205 ms

完整流程测试将 HTTP 交互和异步阅卷分开核验。RocketMQ 消息投递成功不等同于成绩已经完成持久化；必须等待 Worker 完成消费，再以数据库中 `grade_result.status = 'COMPLETED'` 的记录数作为最终成绩验收依据。

该轮测试的初始 300 秒等待窗口结束时，成绩核验快照为 997/1000；随后延长等待，剩余 3 条阅卷也全部完成。因此本仓库将完整流程默认阅卷核验等待时间调整为 1800 秒（30 分钟），并允许通过 `-GradingWaitSeconds` 延长至最多 3600 秒，避免把异步处理耗时误判为永久失败。

## 指标口径

- 虚拟用户数（VUs）不是 TPS；
- 稳态吞吐量按实际 HTTP 样本时间窗口计算；
- HTTP 错误率只反映 JMeter HTTP 请求与断言结果；
- GRADE 消息 `SENT` 表示 Outbox 发布成功，不代表消费者已完成阅卷；
- 完整流程最终通过条件为 1000 条考试记录已交卷、答案记录齐全、1000 条成绩均为 `COMPLETED`，且对应 GRADE Outbox 事件已发送。
